# Быстрый старт: Deel Card Adapter

## ✅ Адаптер готов к использованию!

### Что уже сделано:

1. ✅ Создан адаптер `deel-adapter.tsx`
2. ✅ Зарегистрирован в системе
3. ✅ Поддерживает все типы транзакций Deel
4. ✅ Автоматическое определение категорий по MCC кодам
5. ✅ Обработка declined транзакций
6. ✅ Парсинг CSV с вложенным JSON

## 🚀 Как использовать:

### 1. Откройте страницу импорта

Перейдите на страницу загрузки транзакций в вашем приложении.

### 2. Выберите Deel Card

В селекторе банков выберите **"Deel Card"**.

### 3. Загрузите CSV файл

Перетащите или выберите файл `deel-transactions.csv` из Deel.

### 4. Проверьте результат

Система автоматически:

- Распарсит все транзакции
- Определит Credit/Debit
- Присвоит категории
- Конвертирует в USD
- Сохранит в базу данных

## 📊 Что обрабатывается:

### Типы транзакций:

- ✅ **POS_TX** - Покупки (→ Debit)
- ✅ **DEPOSIT** - Пополнения (→ Credit)
- ✅ **WITHDRAWAL** - Снятия (→ Debit)
- ✅ **REFUND** - Возвраты (→ Credit)
- ✅ **FEE** - Комиссии (→ Debit)

### Валюты:

- ✅ Автоматическая конвертация в `accountCurrency` (обычно USD)
- ✅ Поддержка IDR, GBP, USD, EUR, и других валют

### Категории:

- ✅ Автоматическое определение по MCC кодам
- ✅ 15+ предустановленных категорий
- ✅ Легко расширяется

## 🔧 Настройки (опционально):

### Исключить declined транзакции

В файле `deel-adapter.tsx` раскомментируйте:

```typescript
if (raw.status === 'DECLINED') return null;
```

### Использовать оригинальную валюту

Измените:

```typescript
const amount = Math.abs(parseFloat(raw.originalAmount || '0'));
let currency: CurrencyCode = (raw.originalCurrency as CurrencyCode) || 'USD';
```

### Добавить новые MCC категории

Добавьте в `MCC_CATEGORIES`:

```typescript
'1234': 'Ваша категория',
```
